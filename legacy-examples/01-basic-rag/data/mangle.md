Mangle is a tool for building and running RAG pipelines. It is designed to be simple, flexible, and extensible.

It is built on top of a number of open source libraries, including GenKit, LangChain, and Go-OpenAI.

Mangle provides a number of features that make it easy to build and run RAG pipelines, including:

* A simple, declarative API for defining RAG pipelines.
* A flexible, extensible architecture that allows you to easily add new components.
* A powerful, easy-to-use CLI for running RAG pipelines.
* A web-based UI for visualizing and debugging RAG pipelines.

Mangle is a great tool for anyone who wants to build and run RAG pipelines. It is easy to use, flexible, and extensible.
