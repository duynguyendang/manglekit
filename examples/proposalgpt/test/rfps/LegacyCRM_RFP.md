# Request for Proposal: CRM Modernization

**Title:** Legacy CRM Replacement Project
**Date:** 2024-05-01
**Budget:** $200,000

## 1. Background
Our current CRM system is a customized **monolith** built 10 years ago. It is hosting on-premise and has become a bottleneck for our sales team.

## 2. Problem Statement
* The system is extremely **slow** during peak hours.
* We have **performance issues** with reporting.
* It is a single point of failure (SPOF).

## 3. Requirements
We want to migrate to a modern solution. 
* We are interested in a **Salesforce** integration or a custom cloud solution.
* We want to move away from the **legacy system**.

## 4. Constraints
* Must ensure **Data sync latency < 5 mins**.
* We want to avoid a "Big Bang" migration if possible.
